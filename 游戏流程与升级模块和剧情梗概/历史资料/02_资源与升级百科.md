# 资源与升级百科

本文记录当前代码的规则。记 `Lv` 为购买前等级；资源通常取整数，具体实现的 `whole` 是四舍五入。卡片描述与实际判定有差别时，以实际计算为准；并非全部高阶概念都有独立玩法。

## 思维资源、产出和存储

| 项目 | 当前效果与条件 |
| --- | --- |
| 扰动 | 容量 1000；念头阶段基础每 1 秒增长 `1 + 成长量等级`，消耗 100 扰动自动转化 1 念头。念头满仓时不能转入，不扣这部分扰动。 |
| 念头 | 初始容量 1000；自然基础每 3 秒产生 `1 + 成长量等级 + 种族反哺`。点击产生相同基础量，网络扩展另加点击量，3 秒内连续点击第 N 次额外 `floor(N/5)`。 |
| 思维节点 | 思维萌芽后每 10 秒尝试消耗 100 念头得到 1 节点；上限 10，知识积累后 20；每个现存节点令念头自然速度乘以 `1 + 0.0001 × 节点数`。 |
| 思维链接 | 知识积累后，手动消耗 3 节点得到 1 链接；上限 10。 |
| 思维网络 | 知识积累后，手动消耗 3 链接得到 1 网络；上限 10。首次形成后网络功能保持解锁，即使库存网络被消费。 |
| 思想 | 购买思想遗产后消耗 1 网络生成 1 思想；初始上限 10。意志目前没有相应可玩转化。 |
| 思维仓库 | 容量 `1000 + 本轮仓库等级×500 + 永久仓库等级×250`；每次本轮升级成本 `200 + 当前等级×200` 念头。第一次需萌芽，第二次需知识积累，之后需已形成网络；另要求累计念头至少 100。 |

频率倍率：等级 0 为 1；等级 ≥1 时为 `0.95 × 0.97^(min(Lv,20)-1)`。扰动间隔等于该倍率秒，念头间隔为 `3 × 倍率 / (1+0.0001×节点数)` 秒；超过 20 级的频率效果在当前公式中不再缩短。

## 思维升级与特殊选项

| 选项 | 开放与费用 | 当前效果 |
| --- | --- | --- |
| 思维频率 | 累计 50 念头；`8 + 8×Lv` 念头 | 同时缩短扰动和念头自动间隔，公式见上。 |
| 成长量增加 | 累计 50；`10 + 12×Lv` 念头 | 扰动和念头每次生成的基础量各 +1。 |
| 网络扩展 | 形成网络；`20 + 15×Lv` 念头 | 每次主动点击额外 +1 念头，不增加自然生成。 |
| 灵语体 | 网络已形成、累计 200，花 200 念头特殊解锁；升级 `200 + 200×Lv` 念头 | 每级基础种族资源自动获取效率 +0.1%；解锁标志跨轮保留，等级每轮重置。 |
| 思维萌芽 | 累计 ≥100 且支付 100 念头 | 开放节点定时消耗合成。 |
| 知识积累 | 已有萌芽、拥有 ≥3 节点，支付 100 念头 | 节点容量 10→20，开放链接和网络手动转化。 |
| 生命的萌芽 | 选载体后在特殊升级免费解锁 | 每次主动点击额外获得 1 当前世界基础种族资源；受容量限制，自动增长不触发；每轮重置。 |

普通升级初始上限 10，之后为 50、100、300、600、800、1000；达到上限后在特殊升级花对应资源购买下一档，上限突破费用等于下一档数值，突破记录跨轮回保留。代码中 1000 没有下一档；不应描述为无限升级。

## 种族资源及转化

| 世界观 | 基础资源 | 当前可主动消耗的高阶转化 |
| --- | --- | --- |
| 魔法 | 魔力 | 100 魔力→1 规则碎片；10 碎片→1 规则之脉；10 脉→1 规则本源；10 本源→1 世界本源。 |
| 修仙 | 灵气 | 100 灵气→1 法；10 法→1 道。功德与业力目前没有正常获取路径。 |
| 科技 | 科技点 | 选择生物或机械后，100 科技点→1 血肉点或机械点。 |

基础资源容量 300，高阶容量 20；每级本轮种族仓库各 +200，每级永久种族仓库各 +100。本轮扩容成本 `100 + 100×当前等级` 基础资源；后续等级需按顺序达成载体能力、第一阶段、世界观能力等前置。高阶转化需超凡适应遗产、种族第一阶段、世界观能力、相应资源阶位及库存空间，且需主动操作。每种可转化出的高阶资源可消耗 1 点用于本轮灾难观察，一轮只需一次。

基础种族资源每秒的基础量为 `1 + 资源涌流遗产等级 + 本轮社会产出 + 是否有光能摄取`，再乘以 `1 + (灵语体等级 + 种族资源效果数)/1000`；小数在内部累积后按整数发放，满仓受限。

## 种族基本升级及实际影响

| 种族 | 依次四项 | 实际效果类型依次为 |
| --- | --- | --- |
| 人类 | 体能训练、敏捷与柔韧、记忆整理、创造实践 | 准备、强化准备、念头、成本 |
| 动物 | 营养摄取、敏捷反应、本能训练、环境抗性 | 资源、强化准备、念头、考验难度 |
| 植物 | 扎根生长、营养汲取、生长延续、形态分化 | 资源、念头、成本、强化准备 |

每次基础属性升级初始 +1.0%，阶段效率选项每次使每级再 +0.1%。基础属性每累计 10%：准备类型给准备 +1、强化准备 +2、资源类型自动资源速度 +0.1%、成本类型种族升级折扣 +1%；念头类型每 20% 每次念头 +1；考验难度类型每 20% 难度 −1。费用为 `round((2 + floor(全部种族升级等级/20) + floor(当前项等级/20)) × max(0.3, 1 − min(70, 成本效果 + 结构稳固等级×10)/100))`。

任一属性达 100%、200%、300%……可选阶段方向：已形成的属性乘 `1 + 当前阶段×3%` 后四舍五入；或每级属性增长幅度 +0.1%；或增加一个本轮成长维度。永久成长维度另用回想购买。世界观附加方向的具体名称和效果映射，以及所有扩展名称，见完整程序依据 `speciesUpgradeDefs`；部分旧方向只有已购买等级才显示，实际作用仍生效。

## 一次性种族和世界观能力

每种族能力按列表顺序解锁，依次花费 20、30、40……基础种族资源；必须先解锁前一项。

| 种族 | 能力 | 当前关键作用 |
| --- | --- | --- |
| 人类 | 思维拓宽、想象力萌芽、创造性开发、记忆训练 | 分别可满足危机思维条件、参与解析、防护筹备成本 12→6、成功抵御时多留 1 条线索。 |
| 动物 | 本能突破、敏捷强化、力量爆发、体质增强、生存能力提升、心脏强化 | 分别提供未入档预警、延续族群成本 −2、辅助防护、满足身体条件、辅助生存准备、危机存活后恢复最多 8 基础资源。 |
| 植物 | 光能摄取、二氧化碳合成、水生适应、空气养分汲取 | 分别每秒基础资源 +1、储备筹备成本 12→6、辅助生存准备、危机存活后恢复最多 8 基础资源。 |

世界观能力需先解锁本族第一个能力，花 35 基础资源：魔力共鸣（观察可辅助防护）、灵机调息（可满足生存准备）、环境监测（观察筹备成本 12→6）。能力文字所暗示的高阶演化并不代表已有完整功能。

## 永久遗产

| 遗产 | 消耗回想 | 效果与限制 |
| --- | --- | --- |
| 思维仓库／种族仓库 | `2+当前等级`；各最多 5 级 | 后续每轮容量分别 +250 / +100 每级。 |
| 轮回记忆、思想上限、超凡适应、世界观专精 | 各 2 | 分别开放记忆应对、思想转化、资源阶位加快与高阶转化前置、后续专精选择。 |
| 族群维度 | 3 | 后续轮回开放族群与传承。 |
| 文明维度 | 4 | 需先开放族群且当前轮回至少为第 2 轮；第 3 轮及以后可建立。 |
| 初始意识 | 每级 1，最多 5 级 | 下一轮开场初始念头 +2 / 级。 |
| 资源涌流／结构稳固 | 每级 2；最多 3 / 5 级 | 每级基础种族产出 +1 / 秒；或种族升级折扣 +10%，总折扣上限 70%。 |
| 成长维度 | `2+2×当前等级`，最多 5 级 | 永久增加种族属性成长维度。 |
| 方案协作 | `2+当前等级`，最多 3 级，需族群遗产 | 每级方案上限 +1。 |
| 考验准备 | `2+当前等级`，最多 13 级，需族群遗产 | 每级准备时间 +2 分钟；总时长封顶 30 分钟。 |
