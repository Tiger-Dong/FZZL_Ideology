# 升级体系迭代记录

本轮依据用户修改的《FZZL 升级体系重构方案与词条文案》进行结构迭代，执行文档末尾“先分组、再百科、后扩展机制”的顺序。未填写和存在冲突的细节暂不推断。

## 本轮落地

| 模块 | 当前可执行内容 |
| --- | --- |
| 思维 | 产出、容量、资源转化、灵与身前置与思维升级上限突破。 |
| 载体 | 仓库、本体素质、既有一次性能力、世界观能力、资源转化与载体升级上限。 |
| 发展探索 | 生命载体选择、生命的萌芽、种族经历、阶段方向、世界观专精、已购买的旧方向、族群文明与异界。 |
| 灾变应对 | 探测、征兆方向、筹备、方案起草和落实、保全选择与提前迎接考验。 |
| 回响恒铸 | 结算页永久遗产，进行期间禁用。 |

使用思绪流动、思想萌发、灵感、灵与身、知识串联、知识节点、思绪链接等新名称。三种载体的四项素质也按修订文档命名。ID 和存档键继续沿用原值，旧的特殊升级／社会标签会转到发展探索。原有费用、属性、能力、考验和遗产参数继续使用原型值。

卡片收敛为名称、短描述、预览和操作；详细说明可从卡片进入百科。百科加入五模块定位，以及认知外化、动物双轴、植物觉醒等明确标为设计储备的内容。回想的界面名称统一为回响。

## 未在本轮更改的设计项

1. 新产出费用与倍率、节点 30 秒／500 念头合成、独立链接和网络仓库、100 网络凝结思想等数值调整。
2. 素质改为数值制及每属性 10/30/50/80/100 三选一特性。特性幅度及联动被动仍为空白。
3. 人类四线并行、动物双轴和植物觉醒前后结构切换，目前只录入设计词条，没有虚构可购买效果。
4. 动态 0–10 灾难、连续考验、非致命失败损失、新灾难目录和新回响遗产。

文档中需校准：链接初始容量同时出现 5 和 3；形成网络需 10 链接但初始容量不足；100 网络凝结思想与网络初始容量 3 的承载关系；“节点／链接满仓阻止念头增长”的重复句；初始意识费用公式与“每级 1 回响”的差别。下一轮应先确认这些依赖，再实施相应数值及机制。
