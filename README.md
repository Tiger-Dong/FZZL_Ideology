# FZZL

“意识、种族与轮回”独立网页文字增量游戏，当前为单页原型。

## 运行

直接在浏览器打开 [index.html](index.html)，或在本目录运行 `python3 -m http.server 8000` 后访问 `http://localhost:8000`。试玩存档保存在当前浏览器；“重置试玩”会清除进度。
